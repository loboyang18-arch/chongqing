**可选字段：**

| 字段名 | 类型 | 说明 |

| `tag_high_vol` | bool / int | 是否高波动日 |
| `tag_extreme` | bool / int | 是否异常/极端日 |
| `model_name` | str | 模型名称 |
| `run_id` | str | 实验编号 |

## 3. 有效评估样本规则

### 3.1 点级有效样本

逐点误差类指标使用点级有效样本。

**定义：** 满足以下条件的记录进入点级指标计算：

- `y_true` 非空  
- `y_pred` 非空  
- `hour` 在 0～23  
- `date` 可解析  

**适用指标：** MAE、RMSE  

### 3.2 日级有效评估日

按日 shape 类指标必须基于**完整日**。

**有效评估日定义（原文表述）：** 某自然日被认定为有效评估日，当且仅当满足：

1. 该日 `hour` 恰好覆盖 0～23 共 24 个小时；  
2. 真实值和预测值均完整存在；  
3. 真实曲线方差 \(\mathrm{var}(Y_d^{true}) > 0\)；  
4. 预测曲线方差 \(\mathrm{var}(Y_d^{pred}) > 0\)。  

**若第 4 条不满足**（例如预测为平线），按以下规则处理：

- 对 Pearson 相关系数：该日 \(\mathrm{corr}_d = 0\)；  
- 该日仍计入有效评估日分母；  
- **不允许静默丢弃**。  

这样可以防止「平线预测」通过剔除异常日获得虚高结果。

**适用指标：** Profile Correlation、Negative-Correlation Day Ratio、Amplitude Error、Direction Accuracy、Peak Hour Error、Valley Hour Error、Normalized Profile MAE、Turning Point 系列、Block 系列  

**执行口径勘定（与上条「当且仅当含第 4 条」的逻辑衔接）：**

- 将 **\(D_{\mathrm{valid}}\)** 定义为：满足上述第 **1、2、3** 条的完整自然日（真实方差 > 0，且 24 点真值与预测值均存在）。  
- 对满足 1、2、3 但 **预测方差为 0** 的日子：令 \(\mathrm{corr}_d = 0\)，**仍属于** \(D_{\mathrm{valid}}\)，参与 `profile_corr` 的逐日平均及 `neg_corr_day_ratio` 的分母与分子统计。  
- 对不满足 1、2、3 的日子（缺时刻、真值常数等）：**不进入** \(D_{\mathrm{valid}}\)，计入 `invalid_shape_days`（口径在实现文档中与 `total_calendar_days` 关系写清）。  

若产品方最终选择「预测方差为 0 的完整日从 \(D_{\mathrm{valid}}\) 剔除」，须在标准修订版中单点勘误。

### 3.3 评估输出中必须同时返回以下统计量

| 字段名 | 含义 |
|--------|------|
| `total_calendar_days` | 评估窗口内明细表涉及的自然日去重数（或日历跨度定义，实现中固定） |
| `valid_point_count` | 点级有效样本数 |
| `valid_shape_days` | \(\|D_{\mathrm{valid}}\|\)（按 §3.2 勘定后） |
| `invalid_shape_days` | 无法作为 shape 有效日的天数 |
| `invalid_shape_day_ratio` | `invalid_shape_days / total_calendar_days`（分母定义与实现固定文档一致） |

## 4. 指标定义与计算口径

### 4.1 MAE

**定义：**

\[
\mathrm{MAE} = \frac{1}{N} \sum_{i=1}^{N} \left| \hat{y}_i - y_i \right|
\]

**输入：** 点级有效样本。  

**输出字段：** `mae`  

**说明：** 基于所有点级有效样本计算；不要求完整日。

### 4.2 RMSE

**定义：**

\[
\mathrm{RMSE} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} \left( \hat{y}_i - y_i \right)^2}
\]

**输入：** 点级有效样本。  

**输出字段：** `rmse`

### 4.3 Profile Correlation

**主指标选型：** Pearson 相关系数。

**每日定义：** 对每个有效评估日 \(d\)，构造两个长度为 24 的向量（按 `hour` 0～23 排序对齐）：

\[
Y_d = [y_{d,0},\ldots,y_{d,23}],\quad \hat{Y}_d = [\hat{y}_{d,0},\ldots,\hat{y}_{d,23}]
\]

\[
\mathrm{corr}_d = \mathrm{Pearson}(\hat{Y}_d,\, Y_d)
\]

当预测序列方差为 0 时，\(\mathrm{corr}_d = 0\)（该日仍留在 \(D_{\mathrm{valid}}\)，见 §3.2）。

**总体 profile_corr** 为所有 \(d \in D_{\mathrm{valid}}\) 的 \(\mathrm{corr}_d\) 的**简单算术平均**：

\[
\mathrm{profile\_corr} = \frac{1}{|D_{\mathrm{valid}}|} \sum_{d \in D_{\mathrm{valid}}} \mathrm{corr}_d
\]

**输出字段：** `profile_corr`；可选 `daily_profile_corr`（按日明细表或序列）。  

**说明：** 若某日预测序列方差为 0，则 \(\mathrm{corr}_d = 0\)；不允许删除该日。

### 4.4 Negative-Correlation Day Ratio

**定义：**

\[
\mathrm{neg\_corr\_day\_ratio} = \frac{\#\{ d \in D_{\mathrm{valid}} : \mathrm{corr}_d < 0 \}}{|D_{\mathrm{valid}}|}
\]

**分母：** 固定为 **valid_shape_days**（即 \(|D_{\mathrm{valid}}|\)），**不是**评估窗口内所有日历天。  

**输出字段：** `neg_corr_day_ratio`、`neg_corr_day_count`（分子中的天数）

### 4.5 Amplitude Error

**每日定义：**

\[
\mathrm{amp}_d^{true} = \max(Y_d) - \min(Y_d)
\]

\[
\mathrm{amp}_d^{pred} = \max(\hat{Y}_d) - \min(\hat{Y}_d)
\]

\[
\mathrm{amp\_err}_d = \left| \mathrm{amp}_d^{pred} - \mathrm{amp}_d^{true} \right|
\]

**总体：**

\[
\mathrm{amplitude\_err} = \frac{1}{|D_{\mathrm{valid}}|} \sum_{d \in D_{\mathrm{valid}}} \mathrm{amp\_err}_d
\]

**输出字段：** `amplitude_err`；可选 `daily_amplitude_err`

### 4.6 Direction Accuracy

**每日定义：** 对每个有效评估日，计算相邻小时差分（\(t = 1,\ldots,23\)）：

\[
\Delta y_{d,t} = y_{d,t} - y_{d,t-1},\quad \Delta \hat{y}_{d,t} = \hat{y}_{d,t} - \hat{y}_{d,t-1}
\]

\[
\mathrm{dir\_acc}_d = \frac{1}{23} \sum_{t=1}^{23} \mathbf{1}\left\{ \mathrm{sign}(\Delta \hat{y}_{d,t}) = \mathrm{sign}(\Delta y_{d,t}) \right\}
\]

**总体：**

\[
\mathrm{direction\_acc} = \frac{1}{|D_{\mathrm{valid}}|} \sum_{d \in D_{\mathrm{valid}}} \mathrm{dir\_acc}_d
\]

**平台期处理：** 当 \(\Delta y_{d,t} = 0\) 时，默认仍参与计算；\(\mathrm{sign}(0) = 0\)；若预测差分也为 0，则记为命中。  

**输出字段：** `direction_acc`

### 4.7 Normalized Profile MAE

**每日标准化：** 对真实曲线与预测曲线分别做 z-score：

\[
z(Y_d) = \frac{Y_d - \mu(Y_d)}{\sigma(Y_d)},\quad
z(\hat{Y}_d) = \frac{\hat{Y}_d - \mu(\hat{Y}_d)}{\sigma(\hat{Y}_d)}
\]

（\(\sigma\) 为样本标准差；若某日 \(\sigma=0\) 已在 \(D_{\mathrm{valid}}\) 规则中排除或单独处理，与实现一致。）

**逐日：**

\[
\mathrm{norm\_mae}_d = \frac{1}{24} \sum_{t=0}^{23} \left| z(\hat{y}_{d,t}) - z(y_{d,t}) \right|
\]

**总体：**

\[
\mathrm{normalized\_profile\_mae} = \frac{1}{|D_{\mathrm{valid}}|} \sum_{d \in D_{\mathrm{valid}}} \mathrm{norm\_mae}_d
\]

**输出字段：** `normalized_profile_mae`

### 4.8 Peak Hour Error

**每日：**

\[
\mathrm{peak}_d^{true} = \arg\max_t\, y_{d,t},\quad \mathrm{peak}_d^{pred} = \arg\max_t\, \hat{y}_{d,t}
\]

\[
\mathrm{peak\_err}_d = \left| \mathrm{peak}_d^{pred} - \mathrm{peak}_d^{true} \right|
\]

**总体：** 对 \(d \in D_{\mathrm{valid}}\) 的 \(\mathrm{peak\_err}_d\) 取算术平均。  

**并列峰值：** 若存在多个最大值，取**最早**出现的小时索引。  

**输出字段：** `peak_hour_error`

### 4.9 Valley Hour Error

定义与峰值同理，使用 \(\arg\min\)。**并列谷值**取最早小时。  

**输出字段：** `valley_hour_error`

### 4.10 Turning Point Match Rate

**转折点定义：** 对逐日 24 点曲线计算一阶差分；当差分**符号发生变化**时，认定为一个转折点（如 +→- 视为峰类转折，-→+ 视为谷类转折）。  

**容差规则：** 若预测转折点与真实转折点对应的小时索引之差的绝对值 \(\le 1\)，视为命中。  

**指标：**

- `turning_point_match_rate`：在真实每个转折点上，是否存在容差内的预测转折，按真实转折计数比例汇总（与实现中「对每个真实转折找最近预测」一致时，在代码注释中写清）。  
- `turning_point_offset_mean`：所有已匹配转折点对的平均绝对小时偏差。  

**输出字段：** `turning_point_match_rate`、`turning_point_offset_mean`

### 4.11 Block 系列指标

#### v1.0 默认块段定义

| 逻辑名 | 小时范围 |
|--------|----------|
| `block_overnight` | 0–5 |
| `block_morning_peak` | 6–11 |
| `block_midday` | 12–16 |
| `block_evening_peak` | 17–21 |
| `block_night` | 22–23 |

如项目采用市场特定块段，必须在配置中**显式覆盖**，不允许临时改写。

#### 4.11.1 Block MAE

对每个块段，先求块内**均价**（对落入该块的小时点求平均），再算 \(|\,\text{pred\_block\_mean} - \text{true\_block\_mean}\,|\)，按日得到每日块 MAE，再对有效评估日汇总（具体是先对日平均再对日平均，与 `shape_metrics` 实现对齐）。  

**输出字段：**

- `block_mae_overnight`  
- `block_mae_morning_peak`  
- `block_mae_midday`  
- `block_mae_evening_peak`  
- `block_mae_night`  

#### 4.11.2 Block Amplitude Error

对每个块段，计算块内 \(\max - \min\) 的振幅，再比较预测与真实的振幅差的绝对值，按日平均后再对 \(D_{\mathrm{valid}}\) 汇总。  

**输出字段：**

- `block_amp_err_overnight`  
- `block_amp_err_morning_peak`  
- `block_amp_err_midday`  
- `block_amp_err_evening_peak`  
- `block_amp_err_night`  

#### 4.11.3 Block Rank Accuracy

对每日各块段**真实均价**排序，与**预测均价**排序比较；若排序**完全一致**，该日记 1，否则 0。总体为 \(D_{\mathrm{valid}}\) 上的平均命中率。  

**输出字段：** `block_rank_acc`

## 5. 分场景统计规则

所有主指标必须支持按标签切片。

**支持的标准标签：** `typical`、`high_vol`、`extreme`、`weekend`、`holiday`（如有）  

**切片规则：** 若按日切片，标签粒度必须是**日级**；某日若命中某标签，则该日全部 24 点进入对应切片后再调用点级/日级指标流水线（与 `segment_col` 设计一致）。

## 6. Composite Score 规范

### 6.1 原则

Composite Score **仅用于**同任务、同数据集、同评估窗口下的模型排序，**不能**跨项目直接比较。

### 6.2 归一化方式

采用**相对固定基线比值**归一化。

**固定基线模型：** 每个任务须指定一个固定基线，例如：

- DA 推荐：`naive_same_hour_lag24`  
- RT 推荐：`naive_lag24` 或项目约定稳健基线  

**对「越小越好」指标：**

\[
m_{\mathrm{norm}} = \frac{m_{\mathrm{model}}}{m_{\mathrm{baseline}}}
\]

适用：MAE、RMSE、`amplitude_err`、`neg_corr_day_ratio`、`peak_hour_error`、`valley_hour_error` 等（以落地清单为准）。  

**对「越大越好」指标：** 先转为损失型：

\[
\mathrm{loss}_{\mathrm{corr}} = 1 - \mathrm{profile\_corr},\quad
\mathrm{loss}_{\mathrm{dir}} = 1 - \mathrm{direction\_acc}
\]

再按：

\[
\mathrm{loss}_{\mathrm{norm}} = \frac{\mathrm{loss}_{\mathrm{model}}}{\mathrm{loss}_{\mathrm{baseline}}}
\]

**基线为 0 的防护：** 若分母为 0，须在 `composite.py` 中定义 `eps` clip 或回退为 1.0 / 极大惩罚等，并写入变更日志。

### 6.3 DA Composite Score

\[
\mathrm{Score}_{DA} = 0.25 \cdot \mathrm{mae}_{\mathrm{norm}}
+ 0.30 \cdot \mathrm{corr\_loss}_{\mathrm{norm}}
+ 0.20 \cdot \mathrm{neg\_corr}_{\mathrm{norm}}
+ 0.15 \cdot \mathrm{amp\_err}_{\mathrm{norm}}
+ 0.10 \cdot \mathrm{dir\_loss}_{\mathrm{norm}}
\]

### 6.4 RT Composite Score

\[
\mathrm{Score}_{RT} = 0.30 \cdot \mathrm{mae}_{\mathrm{norm}}
+ 0.20 \cdot \mathrm{corr\_loss}_{\mathrm{norm}}
+ 0.20 \cdot \mathrm{neg\_corr}_{\mathrm{norm}}
+ 0.20 \cdot \mathrm{amp\_err}_{\mathrm{norm}}
+ 0.10 \cdot \mathrm{dir\_loss}_{\mathrm{norm}}
\]

## 7. 单点预测模型适配规则

若模型不是按日输出完整 24 点曲线，而是**单点预测模型**，则：

**必须评估：** MAE、RMSE、分场景 MAE/RMSE。  

**条件评估：** 只有在单点结果可按自然日**完整拼接为 24 点曲线**时，才能评估：

`profile_corr`、`neg_corr_day_ratio`、`amplitude_err`、`direction_acc`、peak/valley、block 等指标。  

否则这些指标记为 **`not_applicable = True`**，**不允许**用不完整曲线强行计算 shape 指标。

## 11. 最低落地要求

v1.0 阶段，至少要求统一以下内容：

## 修订与对齐说明（长版整理时增补）

1. **RMSE：** 常见误写为 \(\sqrt{\frac{1}{N}\sum}\) 仅罩在求和上；本附录采用标准 **均方根误差** 定义。  
2. **§3.2：** 原文「当且仅当」四条与「预测方差为 0 仍计分母」并列时的逻辑，已通过 **\(D_{\mathrm{valid}}\) 勘定** 小节写清推荐实现。  
3. **Turning point 容差：** 本附录为 **≤1 小时**；现有 [`src/shape_metrics.py`](../src/shape_metrics.py) 默认 `tol_hours=2`，代码对齐时须按附录修改或在配置中显式声明差异。  
4. **Block 命名：** 附录使用 `overnight` / `morning_peak` 等；旧代码中 `dawn` / `morning` 等需在配置中做**显式映射**，禁止混用。  
5. **主文档：** 正文见 [电价预测模型量化评估标准_v1.0.md](./电价预测模型量化评估标准_v1.0.md)。
