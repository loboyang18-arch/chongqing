**文档版本**：2026-05-20

## 1. 动机

借鉴高光谱分类模型 **SSRN**（Spectral–Spatial Residual Network）的 3D 卷积思想，在 V18/V24 电价网格 `(C, H_SLOTS, 7)` 上尝试 **光谱–空间分离残差**，并与 V25 `DualHeadResConv2d` 同数据、同切分对比。

---

## 2. 数据与训练设定（与 V25 对齐部分）

| 项目 | 设定 |
|------|------|
| 特征 | V24 `chongqing_market_join.csv`，34 通道 |
| 目标 | `market_clearing_price` → 小时均值 |
| 上下文 | **5+0**（无 after，避免未来泄漏） |

| 优化 | AdamW lr=1e-3，100 epoch 末轮权重，dropout=0.2 |

---

## 3. 结构演进（三次迭代）

### 3.1 伪 SSRN（已废弃）

- 体积 `(B, C, 7, H, 1)`：把 **7 天放在深度 D**，空间核 `(1,3,1)` 只沿日内槽。
- **不符合** SSRN 原文「光谱维 + 二维空间」语义；曾在测试上 MAE ~87，属偶然较好，后证明为错误实现。

### 3.2 真 SSRN 布局

- 体积 `(B, 1, C, H, 7)`：**D=特征 C**，**H×W=槽×天**。
- Spectral：`(3,1,1)`；Spatial：`(1,3,3)`。
- 头部曾 **Flatten(64×34×2×3)=13056** → 参数量 ~408 万，严重过拟合。

### 3.3 GAP 版（最终代码状态）

- `final2` 后 **`AdaptiveAvgPool3d(1)`**，`fc_in=64`，参数量 ~75 万。
- 测试指标与全展平几乎无差别，说明瓶颈不在 FC 宽度 alone。

## 4. 测试结果汇总（官方测试窗，42 天）

| 运行 | 结构 | 参数量 | 测试 MAE | profile_corr | 负相关日占比 |
|------|------|--------|----------|--------------|--------------|
| 伪 SSRN 双头 | (C,7,H,1) 错误布局 | ~53 万 | **87.63** | **0.215** | 14.3% |
| 伪 SSRN 单头 5+0 | 同上 | ~48 万 | 87.06 | 0.164 | 28.6% |

| **V25 参考** | 2D ResConv 双头 5+0 | — | **~85.2** | **~0.24** | — |

训练共性：末轮 **train MAE ~0.5–1.1**，**val MAE ~19**，**test MAE ~88–94**，泛化断层明显；验证最优多在 **ep0–40** 附近，满训 100 epoch 无益。

---

## 5. 失败原因归纳

1. **实现迭代成本**：先错布局后改正，真 SSRN 反而劣于错误布局，干扰结论判断。  
2. **过拟合**：样本约 2568/训练窗，深度模型末轮权重不适合直接上测试。  
3. **未做验证早停**：val 最优与 ep99 权重脱节。  
4. **形状任务弱**：profile_corr 长期 ~0.10，约 1/3 测试日曲线负相关。  
5. **相对 V25 无优势**：同特征下 2D ResConv 更简单、MAE 更低、形状更好。

## 6. 结论与后续

| 决策 | 说明 |
|------|------|
| **删除产物** | `output/ssrn3d_da_5p0/`、`*ssrn3d*train.log` 等已清理 |
| **不纳入排行** | 不参与 `run_evaluate_all_models` 主对比表 |

**教训**：3D 分离卷积在电价网格上 **不能照搬高光谱成功路径**；在 ~100 日训练窗下，**V25 2D 残差 + 双头** 仍是 Conv 主线。DA 综合推荐仍以 **V5 Profile / 调参 LGB** 为准（见 `实验报告_精简版.md`、`docs/V25_模型分析报告.md`）。
